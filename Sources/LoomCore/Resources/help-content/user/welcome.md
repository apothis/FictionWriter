# Welcome to Loom

Loom is a local-LLM macOS fiction-writing app. This help panel is your in-app reference.

Two books live here:

- **User Help** — getting started, generation modes, story bible, references, settings, troubleshooting. For writers using Loom day-to-day.
- **Technical Reference** — architecture, data model, pipelines, build/test/run, conventions. For engineers reading the code.

Switch between them at the top of the panel.

## What to read first

If you're new to Loom, start here:

1. **Getting Started → Install + first launch** — get the app running.
2. **Getting Started → Your first project** — create a project and write a scene.
3. **Generation modes** — Continue, Expand, Rewrite, and the rest.
4. **Story Bible** — Characters, Lorebook, knowledge ledger.

If you're returning, the **Reference** sections are non-linear; pick what you need.
